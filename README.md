# 予約経路分析ダッシュボード（v2: GitHub + Vercel + Supabase版）

Beauty Merit の予約CSVを取り込んで、店舗・経路（電話予約／LINE／Hot Pepper／Web予約など）別に
件数・売上・比率を集計するツールです。旧Render版を全面的に作り直しました。

## 前のバージョンからの変更点

- データの持ち方を「1行の巨大JSON」から、**Supabaseの普通のテーブル**（店舗マスタ・経路マスタ・予約データ）に変更。集計はSQL側で行うので、データが増えても重くなりにくくなりました。
- 店舗名の判定を、コードに埋め込んだ大量のif文から、**画面から追加・編集できる「店舗名の自動判定ルール」テーブル**に変更。取込時に店舗を確定すると自動で覚えます。
- 予約経路の表記ゆれも同様に、**「設定」タブの未分類リストから正しい経路へワンクリックで割り当て**できるようにしました。
- 画面に**月次推移の折れ線グラフ**と**経路別内訳のドーナツグラフ**を追加。比較期間も「直前の同じ長さの期間」「前年同月」から選べます。
- ホスティングはRenderの代わりに **Vercel** を使います（GitHubにpushするだけで自動デプロイされ、無料枠でもスリープしにくいです）。

## 全体構成

```
reservation-dashboard/
├── api/                 … Vercel サーバーレス関数（Supabaseとやり取りする裏側の処理）
├── public/              … 画面（index.html / app.js / styles.css）
├── supabase/schema.sql  … Supabaseに作るテーブルの定義
├── package.json
└── vercel.json
```

## セットアップ手順

### 1. Supabaseプロジェクトを用意する

1. https://supabase.com にログイン（旧ツールで使っていたものと同じプロジェクトを使う場合はこの手順は不要です。ただし新しいテーブル構成なので、**新しいプロジェクトを作る方をおすすめします**）
2. 左メニューの **SQL Editor** を開き、`supabase/schema.sql` の中身を全部貼り付けて実行（Run）する
3. 左メニューの **Project Settings → API** を開き、以下の2つをメモしておく
   - `Project URL`（例: `https://xxxxx.supabase.co`）
   - `service_role` キー（`anon` キーではなく `service_role` の方です。他人に見せないでください）

### 2. GitHubにコードを置く

1. GitHubで新しいリポジトリを作成する（例: `reservation-dashboard-v2`）。既存の `reservation-dashboard` リポジトリを上書きしても構いません
2. このフォルダの中身をすべてアップロードする（GitHubの「Add file → Upload files」でこのフォルダの中身をドラッグ＆ドロップでもOKです）

### 3. Vercelにデプロイする

1. https://vercel.com にログイン（GitHubアカウントでログインできます）
2. **Add New → Project** から、さきほどのGitHubリポジトリを選択
3. **Environment Variables** に以下を追加する

   | Key | Value |
   |---|---|
   | `SUPABASE_URL` | 手順1でメモしたProject URL |
   | `SUPABASE_SERVICE_ROLE_KEY` | 手順1でメモしたservice_roleキー |
   | `APP_PASSWORD` | （任意）このツールにかける合言葉。設定すると開くときにパスワードを聞かれます |

4. **Deploy** を押す
5. 発行された `https://xxxxx.vercel.app` を開く

### 4. 動作確認

- `https://xxxxx.vercel.app/api/health` を開いて `{"ok":true}` と出ればSupabaseと接続できています
- トップページを開き、パスワードを設定した場合はログイン画面が出ます

## 店舗マスタの初期登録

初回は店舗が1件も登録されていないので、「設定」タブの「+ 店舗を追加」から、今使っている17店舗を登録してください（ブランド名は任意です）。あとから追加・編集・無効化ができます。

## 使い方の流れ

1. Beauty Meritで予約CSVをダウンロード
2. 「CSV取込」タブでCSVをまとめて選択
3. 各ファイルの店舗を確認（前回選んだファイル名のパターンは自動で選択されます）
4. 「取込実行」を押す
5. 「設定」タブに未分類の経路表記が出ていれば、正しい経路に割り当てる
6. 「ダッシュボード」タブで店舗・期間を選んで確認

## 補足

- CSVの取込は何度でもやり直せます。同じ予約番号のデータは上書きされるだけで重複しません
- 「設定」タブの経路マスタで「集計から除外」にチェックすると、その経路をKPIの合計や比率計算から外せます（表には引き続き表示されます）
